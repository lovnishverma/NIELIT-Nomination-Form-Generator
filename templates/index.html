How it works
  1. Export your Google Form responses as CSV (File → Download → CSV).
  2. Ensure the CSV has a Form_Type column or both Track and Level columns.
  3. Upload the CSV above — one row = one nomination form.
  4. All forms are packed into a ZIP and downloaded automatically.
  5. BOOTCAMP rows use the Bootcamp template; all GOT rows (Basic + Advanced) share the GOT template.

CSV Column Guide
  • Form_Type — e.g. ARVR_BASIC, BDDS_BOOTCAMP
  • Track + Level — e.g. ARVR + Basic (alternative to Form_Type)
  • Name — used in output file names
  • Edu1_Year / Edu1_Degree / Edu1_University … up to Edu5
  • Exp1_Year / Exp1_Area_of_Expertise / Exp1_Centre … up to Exp5
  • Any extra column becomes a placeholder: {ColumnName} or <<ColumnName>>
Auto-Injected Fields
  • {Domain} — full domain name
  • {Course_Name} — e.g. GOT – AR & VR (Basic)
  • {Course_Level} — Basic / Advanced / Bootcamp
  • {Program_Type} — GOT or Bootcamp
  • {Form_Title} — full form title
  • {Today_Date} — today's date
